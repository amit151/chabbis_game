# 26 (Chabbis) — 4-Player Online Android Card Game

## Quick Start to Build Your `.apk` (No Local Setup Needed)

1. **Create Free Firebase Database ($0/month):**
   - Go to https://console.firebase.google.com and create a project (`chabbis-26`).
   - Enable **Realtime Database** (Test mode).
   - Register an Android app with package name `com.chabbis.chabbis_26` and download `google-services.json`.

2. **Upload to GitHub:**
   - Create a free account at https://github.com and create a new repository.
   - Upload all files from this ZIP along with your `google-services.json` in the root folder.

3. **Download Your `.apk`:**
   - Open the **Actions** tab in your GitHub repository and run **Build Android APK**.
   - Download the generated `chabbis-26-release-apk` artifact (`app-release.apk`) and install it on all 4 Android phones!
